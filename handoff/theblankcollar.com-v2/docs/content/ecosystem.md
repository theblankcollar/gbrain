## Section 3 — Why four sites, not one

### EN — Heading: Why four sites, not one
Because each is a different promise. The agency sells outcomes. The tools sell themselves. The venture arm invests — different clock, different risk, different counterparty. Putting them under one URL would blur all three.

Same worldview, four surfaces. Each one commits to doing one thing well.

### DE — Überschrift: Warum vier Seiten, nicht eine
Weil jede ein anderes Versprechen ist. Die Agentur verkauft Ergebnisse. Die Tools verkaufen sich selbst. Der Venture-Arm investiert — andere Zeitachse, anderes Risiko, andere Gegenpartei. Alle drei unter einer URL würde alle drei verwischen.

Dieselbe Weltanschauung, vier Oberflächen. Jede macht eine Sache richtig.
